# TalkType for Mac, shop copy deck

Two screens. Every string below is final-draft copy, ready to paste. Line breaks
marked with ` / ` are intentional; everything else is one run of text.

Voice check: no em dashes, no emojis, no exclamation marks. One origin "I", once,
in the kicker. The app is the subject from there on. "Buy" is the only button verb.

## Why these choices

1. The tabs are scenes, not app names: a stranger sees a place to talk to a friend rather than a list of macOS apps, and the three stages still map one to one.
2. The prompt deck starts with nursery rhymes so the first attempt cannot fail, then walks up to Worcestershire, Statler, Melbourne and a word no engine has met, and finishes on a line someone would actually dictate at work.
3. The states tell the truth in order: waiting, listening, landed. The fallback blames the demo, never the reader, and answers the next question before it gets asked.
4. The beats run act, permission, result. "The pause is allowed" is the wisdom line: every other voice tool penalizes thinking out loud, and this one is built for it.
5. Price copy sells silence. "One payment, then quiet" is the whole offer, and the bullets are the things a buyer would have had to email support to find out.
