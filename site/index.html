The short answers

Before the download.

Why a DMG instead of the Mac App Store?

The App Store edition can hear a shortcut, but it cannot type into another app. Pasting at the cursor needs a permission Apple only grants outside the sandbox. The direct build is notarized by Apple and opens without a warning.

Where does the audio go?

Nowhere by default. Apple's on-device recogniser keeps it on the Mac. Cloud engines only run when a Deepgram or Gemini key is added, and then audio goes straight from the Mac to that provider — never through a TalkType server, because there is no TalkType server.

What happens after payment?

Square sends a receipt, and the confirmation page holds the download plus install steps. The same DMG stays at mac.talktype.app/downloads/TalkType.dmg, so a lost copy is never a lost purchase.

Does it work in password fields?

No, by design. macOS blocks anything that types inside a password box, and TalkType does not try to get around that. Anywhere a paste lands, dictation lands.

Which Macs are supported?

macOS 13 Ventura or newer, Apple Silicon or Intel. The DMG carries one universal binary.
