Good to know

Before the download.

Why a DMG instead of the Mac App Store?

Apple's App Store restricts apps from pasting text into other windows. Since that's the entire point of TalkType, we ship it directly. The build is fully notarized by Apple, so it installs safely without warnings.

Where does the audio go?

Stays on the Mac. Apple's speech engine does the listening right there. If an API key is added for cloud recognition or polish, audio goes from the Mac to that service and nowhere else.

What happens after payment?

Square sends a receipt, and the next page has the download and the install steps. The same DMG stays at mac.talktype.app/downloads/TalkType.dmg, so a lost copy is never a lost purchase.

Does it work in password fields?

No. macOS blocks anything that types into a password box, and that is the right call. Anywhere a paste works, dictation works.

Which Macs are supported?

macOS 13 Ventura or newer, Apple Silicon or Intel. The DMG carries one universal binary.
