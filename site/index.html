The short answers

Before the download.

Why a DMG instead of the Mac App Store?

The App Store sandbox does not allow watching a global key or pasting into another app, which is the whole point of TalkType. The direct build is notarized by Apple and opens without warnings — it just keeps the powers the sandbox removes.

Where does the audio go?

Nowhere by default. Apple's on-device recogniser keeps it on the Mac. Cloud engines only run when a Deepgram or Gemini key is added, and then audio goes straight from the Mac to that provider — never through a TalkType server, because there is no TalkType server.

What happens after payment?

Square sends a receipt, and the thank-you page holds the download plus install steps. The same DMG lives at talktype.app/downloads/TalkType.dmg, so a lost copy is never a lost purchase.

Does it work in password fields?

No, by design. macOS refuses synthetic keystrokes in secured fields, and TalkType does not try to work around that. Everything else that accepts text accepts dictation.

Which Macs are supported?

macOS 13 Ventura or newer, Apple Silicon or Intel. The DMG carries one universal binary.
