Privacy

Audio stays on the Mac.

TalkType has no backend, no account system and no analytics. This page describes exactly what leaves the machine and when. Last updated 2 November 2026.

Default engine

Apple's speech recognition runs on the Mac's Neural Engine. Audio is not uploaded to Apple, and nothing reaches this website or any TalkType server. There is no TalkType server to reach.

Optional cloud engines

Adding a Deepgram or Gemini API key unlocks streaming recognition or a prose polish pass. When those engines run, audio (or the finished transcript, for Gemini) travels directly from the Mac to that provider, using the owner's own key. Deepgram and Google process it under their own terms; TalkType never sees it.

Keys

API keys are stored in the macOS Keychain, in the app's own keychain item. They are not written to preferences files, not synced by TalkType, and not included in any request other than the provider's own authentication header.

History and settings

The last 50 transcripts, vocabulary and preferences live in the app's own container on the Mac. The History tab can clear them at any time. Nothing is uploaded, and there is no device sync.

Data collected by this website

Payments open Square's hosted checkout. Square collects the email address and card details needed for the receipt; that data never touches this site. The site itself sets no analytics cookies and runs no third-party trackers. Server logs at the host record standard request information such as IP address and user agent.

Purchases and support

Email sent to pibulus@gmail.com is kept only as long as the conversation needs it. Receipts stay with Square.

App Store privacy label

The Mac App Store build declares no data collection: no analytics, no identifiers, no advertising, no tracking. The optional cloud engines are disabled until a key is entered by the owner, and the audio still goes only to that provider.
